# Nexus — Where Souls Connect

A romantic social feed that connects people. Full-stack app with Node.js, Express, and SQLite.

## Run

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000)

## Features

- **Feed** – Create and view posts
- **Likes** – Like and unlike posts
- **Comments** – Open comments modal, add comments
- **Romantic theme** – Deep crimson, hypnotic background, elegant typography
